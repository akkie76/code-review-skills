# Code Review Skills

[English](README.md)

CodexとClaude Code向けの、根拠を重視したコードレビューワークフローです。

このSkillは、[『コードレビューの教科書』](https://gihyo.jp/book/2026/978-4-297-15768-5)の
考え方をベースに、AIコーディングエージェント向けに独自に作成したものです。
書籍の内容を再現・網羅するものではありません。

**バージョン:** `v1.0.0` · **ライセンス:** MIT

1.0.0では、文書化したレビュー出力形式を安定した仕様として扱います。一方、指摘の
内容はモデルやプロジェクトの情報などに左右され、すべての不具合の検出や、実行ごとに
同じ指摘が出ることを保証するものではありません。

## すぐに試す

インストールするバージョンを固定するため、リリースタグを指定してcloneします。

```sh
git clone --depth 1 --branch v1.0.0 https://github.com/akkie76/code-review-skills.git
cd code-review-skills
```

### Codex

```sh
mkdir -p ~/.codex/skills
cp -R dist/codex/evidence-code-review ~/.codex/skills/
```

Codexの新しいタスクを開始し、たとえば次のように依頼します。

> `evidence-code-review` Skillを使って、`main`との差分をレビューしてください。正しさ、regression、テストを中心に確認し、ファイルは変更しないでください。

### Claude Code

```sh
mkdir -p ~/.claude/skills
cp -R dist/claude-code/evidence-code-review ~/.claude/skills/
```

Claude Codeの新しいsessionで、たとえば次のように呼び出します。

```text
/evidence-code-review mainとの差分をレビューしてください。正しさ、regression、テストを中心に確認し、ファイルは変更しないでください。
```

プロジェクト単位のインストール、Windowsでの手順、動作確認、更新、削除、トラブル
対応は[インストールガイド](docs/INSTALLATION.ja.md)を参照してください。

## レビューする内容

- 依頼された範囲と、リポジトリ固有のルールを確認します。
- 変更行だけでなく、影響を受ける処理まで追跡します。
- リスクに応じて、正しさ、interface、設計、security、reliability、test、
  documentを確認します。
- 別途変更を依頼されない限り、レビュー対象のコードは変更しません。

## レビュー結果の読み方

対応を求めるコメントには、対応要否とレビュー観点を示すプレフィックスが付きます。

- `MUST`：マージ前に解決すべき、根拠のある問題
- `SHOULD`：通常は対応すべき具体的なリスク。明示的な判断により延期できる
- `BETTER`：具体的な利点がある任意の代替案
- `NITS`：軽微で、マージを妨げない修正

観点には`Functionality`、`Test`、`Simplicity`、`Document`などがあります。指摘には
該当箇所と具体的な根拠、発生条件と影響、妥当な修正の方向性を含めます。

```text
MUST(Functionality): 次の結果を取得する前にページ番号を進める

Location: `src/client.ts:42`
APIが上限件数を返すと、`page`が変わらないため同じページを再取得します。結果が重複し、
リクエスト数も増えるため、次のリクエスト前にページ番号を進めてください。
```

これは形式を示す例です。対応要否、観点、根拠、コミュニケーションルールの詳細は
[レビューコメント規約](docs/REVIEW_COMMENTS.ja.md)を参照してください。

## プロジェクト固有の情報

言語、framework、architecture、test commandはリポジトリごとに異なります。正確な
レビューに必要な情報は、対象リポジトリの`AGENTS.md`、`CLAUDE.md`、またはそこから
参照する文書へ記載してください。バージョン制約、ライフサイクルや並行処理のルール、
architecture上の規約、検証コマンドなどが役立ちます。インストール済みSkillは編集せず、
更新で置き換えられるようにしてください。

## できることと限界

- 結果はモデル、エージェントのバージョン、利用可能なツール、レビュー範囲、プロジェクト
  情報に左右されます。高性能なモデルが助けになる場合はありますが、正確性や完全性は
  保証されません。
- テストや人によるレビューと併用してください。このSkillはどちらの代替でもなく、
  不具合の見逃しや誤検知がゼロになることを保証しません。
- Skill自体が追加権限を与えることはありません。ファイルアクセスや操作時の確認は、
  ホストエージェントとその設定に従います。
- 大きな変更のレビューでは、モデルのtokenを多く消費することがあります。
- [最新の評価レポート](tests/results/2026-10-08-issue-24-v2-evaluation.ja.md)は
  小規模な合成fixtureによる評価であり、実運用のレビュー精度を示すものではありません。
  背景や他のレポートは[評価ガイド](tests/README.ja.md)を参照してください。
