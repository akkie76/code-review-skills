# Content and Publication Policy

## Purpose

This repository publishes an independently authored workflow for code-review
agents. External books and documentation may inform the project, but the
repository must remain useful without reproducing those sources.

## Source-material boundary

Do not commit any of the following unless their publication rights have been
separately verified:

- Manuscripts, proofs, extracted text, screenshots, figures, or tables.
- Sample code or review comments copied from a book or another publication.
- Close paraphrases that preserve a source's distinctive expression or
  explanatory sequence.
- Private correspondence with editors, publishers, or rights holders.

When consulting external material:

1. Extract general principles rather than reusable prose.
2. Design the agent workflow around observable behavior and original rules.
3. Write all public text independently.
4. Use newly created examples that do not mirror a source example.
5. Record public acknowledgements separately from the licensed work.

## Licensing boundary

The repository's MIT License applies only to original material intentionally
published in this repository. It does not relicense books, documentation, or
other referenced works.

## Publication gates

Before changing the repository visibility to public, confirm all of the
following:

- The intended use of any referenced publication has been discussed with the
  relevant editor or rights holder.
- Acknowledgement wording and outbound links have been reviewed.
- No unpublished source material or close derivative has been committed.
- Generated distributions contain only approved, original content.
- The full Git history has been inspected, not only the working tree.
- License, security, contribution, and release documentation is complete.

## References used during development

References may be listed here only when they are already public and the
acknowledgement wording has been approved. Private source files and local file
paths must never be recorded in this repository.
