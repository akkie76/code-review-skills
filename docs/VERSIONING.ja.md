# バージョンと互換性

[English](VERSIONING.md)

公開するCodex・Claude Code向けパッケージには、`VERSION`を正本とする
[Semantic Versioning](https://semver.org/lang/ja/spec/v2.0.0.html)を採用します。
生成された`SKILL.md`には、標準frontmatterの外に
`<!-- skill-version: vX.Y.Z -->`というコメントを記載します。Gitのリリースタグには
同じバージョンへ`v`を付けます。パッケージのdirectory名やSkill名にはバージョンを
含めません。インストール済みの版はこのコメントで確認できます。

## 文書化した出力契約

以下は、利用者や後続ツールが参照できる公開上の出力仕様です。現在の詳細なルールは
[出力契約](../src/core/output-contract.md)に記載しています。

- 対応が必要な指摘のタイトルは`ACTION(Viewpoint):`で始まります。`ACTION`は
  `MUST`、`SHOULD`、`BETTER`、`NITS`のいずれかで、意味は
  [レビューコメント規約](REVIEW_COMMENTS.ja.md)に従います。対応要否を示し、
  確信度や修正工数を示すものではありません。
- `Viewpoint`は`Design`、`Simplicity`、`Naming`、`Style`、
  `Functionality`、`Test`、`Document`のいずれかです。新しい観点は文書化した
  追加的な契約変更として導入できます。現行の一覧が永久に増えないとは保証しません。
  既存の名称の意味を予告なく変更しません。
- 対応が必要な指摘には、場所、根拠、発生条件、影響、修正の方向性を含めます。
  これは必要な情報の定義であり、固定のフィールド名や機械可読のschemaでは
  ありません。表現、段落構成、表示の詳細は改善できます。
- 最終回答では対応要否の順に指摘を示し、重要な未解決の質問、必要に応じて短い
  要約や検証上の制約を続けます。対応すべき指摘がなければ、その旨を明示します。
  実行ごとに同じ文言、指摘件数、行範囲になることまでは保証しません。

## 出力の互換性とレビュー挙動

出力の互換性は、上記の文書化した構造と意味に関するものです。レビュー挙動は、
*どの*不具合を発見し、見逃し、根拠不足として退けるかに関するものです。
追跡方法や根拠確認、誤検知抑制の改善により、出力契約が変わらなくても指摘内容は
変わり得ます。モデル、利用するエージェント、使用可能なツール、プロジェクトの
情報も結果に影響します。互換性のある版でも、同じ指摘や文言は保証しません。

出力契約への追加や、レビュー挙動の重要な変更は、リリースノートに説明し、
関連する評価結果または評価上の制約を記録します。指摘判断の改善だけで、直ちに
出力形式の破壊的変更とみなすわけではありません。

## バージョンの選び方

- **メジャー**：1.0以降、対応要否の削除や意味の変更、タイトルのプレフィックス
  形式の置き換えなど、文書化した出力契約と互換性のない変更。
- **マイナー**：新しい観点など、契約への後方互換のある追加、または重要な新機能。
  利用者が追加に対応する方法も説明します。
- **パッチ**：公開機能を追加しない、互換性のある修正、説明の明確化、配布物の修正、
  レビュー方法の改善。指摘内容が重要な形で変わる場合は、リリースノートと
  評価結果も必要です。

`0.x`およびプレリリースは評価中であり、安定した互換性を保証しません。この間の
破壊的変更は、1.0への早期移行をせず、新しいプレリリース版として公開できます。
ただし、リリースノートで明示し、移行方法を示します。公開済みの版は変更せず、
変更時には新しい版を発行します。

契約要素を非推奨にする場合は、リリースノートで代替手段と移行方法を告知します。
可能な範囲で妥当な移行期間を設け、適切なバージョンで削除します。固定の期間は
約束しません。正しさやセキュリティのため早期変更が必要なら、その理由を説明します。

## リリース時の検査

`make release-check`は`VERSION`の形式と両生成パッケージの表記を検査します。
リリース準備時に英日双方のCHANGELOGとリリースノートを更新してください。
リリースコミットへタグを付けた後、`make release-tag-check`を実行します。
`v<version>`が`HEAD`を指すこと、日付入りのCHANGELOG項目とリリースリンク、
英日リリースノートのタイトルが`VERSION`と一致することも確認します。
変更内容と評価結果をリリースノートが正確に表しているかは、人が確認します。
