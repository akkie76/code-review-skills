# Code Review Skills v0.1.0-beta.1

[日本語](v0.1.0-beta.1.ja.md)

> Draft release notes. Finalize only after the release checklist is complete.

This first beta release provides a shared code-review workflow for Codex and
Claude Code. It emphasizes actionable, evidence-backed findings and suppresses
style-only or speculative comments.

## Included

- Installable `evidence-code-review` skill packages for Codex and Claude Code.
- Risk-based checks across correctness, interfaces, design, clarity, security,
  reliability, tests, and documentation.
- A stable `MUST`/`SHOULD`/`BETTER`/`NITS` comment and output contract.
- English and Japanese review requests and output selection.
- Reproducible offline generation and structural validation.
- Behavioral evaluation fixtures and a manual cross-agent procedure.

## Beta limitations

- Behavioral accuracy still depends on the host agent, model, repository
  context, and available tools.
- The included evaluation runner validates fixtures but does not call an AI
  service; agent behavior is evaluated manually.
- The maintainer-led beta does not accept unsolicited Issues or pull requests.

Follow the installation instructions in the English or Japanese README and
review the Skill before enabling it in a development environment.
