# Code Review Skills v1.0.0

[English](v1.0.0.md)

Code Review Skills v1.0.0は、CodexとClaude Code向けの根拠を重視したレビュー
ワークフローの初回安定版です。文書化した指摘出力契約を安定仕様として提供しますが、
レビュー判断はモデル、利用可能なツール、プロジェクトの文脈に左右されます。

## 安定するもの

公開する契約は、指摘タイトルの`ACTION(Viewpoint):`形式、文書化された対応要否と
レビュー観点、および指摘に必要な対象箇所・根拠・発生条件・影響・修正の方向性です。
契約の詳細と互換性の規則は[バージョン方針](../VERSIONING.ja.md)を参照してください。

出力形式が安定しても、指摘内容が安定するわけではありません。モデル、エージェントの
バージョン、プロジェクト、反復実行の間で、表現、指摘数、行番号、検出率が同一になる
ことは保証しません。すべての不具合を検出できることや、すべての指摘が正しいことも
保証しません。

## v0.1.0-beta.2以降の主な変更

- 質問、要約、断り付きの文を含む補強根拠を検証し、正確で対応不要な対象範囲の注記を
  指摘として扱わないよう、レビュー手順と出力契約を明確化しました。
- 必須のリポジトリ規約への新たな違反、起動を妨げるセットアップ手順、変更によって
  生じた未使用ヘルパー、挙動変更に対応するテスト不足の扱いを明確にしました。
- CodexとClaude Code向けの任意実行ローカル評価runnerを追加しました。revisionごとの
  隔離snapshotと呼び出し根拠を記録します。別途、人手判定の採点手順も追加し、
  エージェントごとに80点を基準とします。
- README、インストールガイド、リリースチェックリスト、サポート方針、脆弱性報告手順を
  安定版向けに更新しました。

## 評価根拠と許容した差異

[v2評価レポート](../../tests/results/2026-10-08-issue-24-v2-evaluation.ja.md)では、
厳密な基本評価でCodexが27/29件、Claude Codeが26/29件合格し、いずれも合意済みの
80%基準を上回りました。評価は29件の合成fixtureと、エージェントごとに6件の診断用
反復で構成されます。Claudeの実行記録は最初のcampaignから再利用し、Codexはtimeout後に
置き換えました。採点はアシスタントの支援を伴うメンテナー判定で、両エージェントの
権限・隔離条件も異なります。この結果は実運用のレビュー精度を測定するものではなく、
結果がSkillによって生じたことを証明するものでもありません。

厳密な採点上の不一致は合格に読み替えず、レポートに残しています。

- Codexは軽微なプロジェクトスタイルの問題を、期待された`NITS(Style)`ではなく
  `MUST(Style)`としました。また、有効なテスト提案を出した一方で、必要な
  `BETTER(Simplicity)`の指摘を省略しました。
- Claude Codeは、効果のない回帰テストを期待された`SHOULD(Test)`ではなく
  `MUST(Test)`としました。また、2件で根拠のない、または不正確な補足を含み、反復評価の
  1件ではデッドコードの位置が不正確でした。

必須の中核的な不具合は検出され、両エージェントが事前合意した基準を超えたため、
メンテナーはこれらの差異を本リリースで許容しました。ただし、厳密な採点では各不一致を
失敗として記録しています。caseごとの判断理由と集計は評価レポートに記載しています。
今後のレビュー挙動の変更は、このスコアだけから効果を推定せず、fixtureと評価上の制約を
踏まえて検証してください。

## インストールと更新

[インストールガイド](../INSTALLATION.ja.md)に従い、`v1.0.0`タグのpackage全体を
インストールしてください。更新時も`SKILL.md`だけをコピーせず、インストール済みの
package全体を置き換えたうえで、バージョン表記が`<!-- skill-version: v1.0.0 -->`である
ことを確認してください。
