# Code Review Skills v0.1.0-beta.1

[English](v0.1.0-beta.1.md)

最初のベータ版として、CodexとClaude Codeで利用できる共通コードレビュー
ワークフローを提供します。根拠があり対応可能なfindingを重視し、スタイルだけの
コメントや推測による指摘を抑制します。

## 内容

- CodexとClaude Code向けの`evidence-code-review` Skillパッケージ
- correctness、interface、design、clarity、security、reliability、test、
  documentationに対するリスクベースの確認
- `MUST`、`SHOULD`、`BETTER`、`NITS`による一貫したコメント・出力contract
- 既存consumer、共有handlerのvariant、同一diff内の実装を追跡する整合性確認
- 危険な入力へのfocused verificationと、最終reviewerが責任を維持したまま行う
  複雑な指摘候補の任意の検証委譲
- 独立した検証と必須の統合確認を伴う、任意の複数エージェント分解
- 利用箇所が残っていないことを確認したうえで、変更が生んだデッドコードを検出する観点
- 英語と日本語によるレビュー依頼・出力選択
- 再現可能なオフライン生成と構造検証
- 行動評価fixtureとエージェント間の手動評価手順
- 根拠を添えたベータ版feedbackを受け付ける構造化Issue form

## ベータ版の制約

- 行動精度はホストエージェント、モデル、リポジトリcontext、利用可能なtoolに依存する
- 評価runnerはfixtureを検証するがAIサービスは呼び出さず、agentの動作は手動評価する
- メンテナー主導のベータ期間中は根拠を添えたIssueを受け付ける。Pull Requestには
  事前の合意が必要であり、返信や修正は保証しない

英語版または日本語版READMEの手順に従い、開発環境で有効化する前にSkillの内容を
確認してください。
