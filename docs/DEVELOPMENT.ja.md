# 開発ガイド

[English](DEVELOPMENT.md)

## ソース構成

共通のレビュー手法は`src/core/`で編集します。任意の技術情報を追加する入口は
`src/technologies/`にあります。generatorはこれらを組み合わせ、対応する各
エージェント向けの自己完結したパッケージを`dist/`へ生成します。生成された
パッケージを直接編集しないでください。

## 変更手順

1. `src/core/`または`src/technologies/`へ、必要最小限でベンダー非依存の変更を行う
2. `tests/cases/`の行動評価を追加または更新する
3. `make build`を実行する
4. `make test`を実行する
5. 生成差分に意図しない内容や参照元固有の内容がないか確認する
6. 影響を受けるcaseをCodexとClaude Codeで手動評価する

非公開開発中の手動評価結果は公開リポジトリ外に記録します。生成物だけの変更は、
次回のbuildで上書きされるため無効です。

## 配布物の保証

- Python標準ライブラリだけでオフライン生成できる
- 各パッケージに有効な`name`と`description`のfrontmatterがある
- 各パッケージが自己完結している
- 再生成しても同じ内容になる
- ローカルパスや非公開資料の識別子を含まない

## 外部からの変更

現在はメンテナー主導で開発しています。根拠を添えたIssueを受け付けますが、
Pull Requestには事前の合意が必要です。受け付ける内容と報告に必要な根拠は
[サポート方針](../SUPPORT.ja.md)を参照してください。
