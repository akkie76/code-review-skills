## Scope and setup

- Evaluator: the fixture author/project maintainer scored their own cases by comparing final outputs with `case.json` after each run.
- Skill package: `dist/codex/evidence-code-review` at commit `6ce83d4` (`v0.1.0-beta.2`). The skill source is unchanged by that commit.
- Agent: Codex CLI `0.158.0-alpha.2.1`, model `gpt-6-luna`, high reasoning effort.
- Each language/case pair used a fresh, ephemeral, read-only session in an isolated Git repository. The skill was installed at project scope before the baseline commit. The fixture patch was applied to the working tree; `git add -N` made newly added files visible in `git diff`.
- The agent saw repository files and the review request only, not `case.json` or its expected findings. English and Japanese requests used the exact text in each case.
- Pass means all required findings and prefixes appeared, prohibited findings did not appear, and the expected findings/no-findings outcome held. It does not mean the model is reliable across repeated runs.
